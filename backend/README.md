# Backend pendiente

Esta carpeta queda reservada para PHP con PDO y PostgreSQL, sin frameworks.
El frontend no abre conexiones a la base de datos. La primera entrega funciona
con un adaptador de demostracion independiente, con datos ficticios.

La implementacion posterior invocara procedimientos mediante CALL y consumira
los diez reportes SQL. Las credenciales permaneceran exclusivamente en el servidor.
